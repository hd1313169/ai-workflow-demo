fb-date-field

。狀態：closed / open；操作：換月 / 選日 / 清除 / 確認。屬性：min / max（YYYY/MM/DD，超出範圍的日期禁用、刪除線）

fbLinkRange：起／訖成對綁定（訖不得早於起）。改「起」日期後，「訖」日曆早於起日的格子會被禁用；若把「起」改到晚於目前「訖」，「訖」會被推移跟上。「起」本身不因「訖」而設上界。

fb-time-field

（時間選單）。狀態：closed / open；操作：時 / 分 上下步進。事件：change{value:"HH:MM"}。屬性：min / max（HH:MM，設了則 clamp 不迴繞）

fbLinkRange：開始／結束時間成對綁定（結束不得早於開始）。

fb-datetime-field

（date picker-使用者登錄紀錄）。日期＋時間複合欄位，格式 YYYY/MM/DD HH:MM；空值顯示 placeholder。狀態：closed / open；操作：選日 + 時/分步進 + 清除 / 確認。事件：change{value}

fbLinkRange：起／訖成對綁定（訖不得早於起，起值改到晚於訖值時推移訖值跟上）。

fb-schedule-dialog

屬性：mode = timed | allday。方法：open(data?) / close()。事件：submit / cancel。（Default / All Day）

fb-info-table

label／value 兩欄唯讀資訊表（ 內 informational table-cell）。內嵌 JSON `[{ label, value }, …]` 或以 rows setter 指定； label 欄固定寬 120px、value 欄可換行，相鄰列白／藍交錯，value 空字串顯示「-」。無排序／篩選／列互動。

fb-loader / .is-loading（按鈕處理中）

。按鈕加 `.is-loading` 並把圖示換成 `fb-loader`：圖示持續旋轉、按鈕不回應點擊。

fb-transfer

雙欄穿梭清單 Dual Listbox。內嵌 JSON `{ items:[{id,label}], value:["id"...], leftTitle, rightTitle }`； 或以 left-title / right-title 屬性覆寫標題。方法：get/set value（右欄 id 陣列）、setData(items, value)。事件：transfer-change { value }。 每欄＝標題（框外）＋方框（灰底搜尋列 + 白底可捲清單）；清單多選（點列切換），中間 4 顆方形鈕 ›（選取右移）»（全部右移）‹（選取左移）«（全部左移），「全部」以搜尋後可見項為準。

（transfer-change 結果顯示於此）

fb-pagination

表格底部分頁列。內嵌 JSON `{ total, page, pageSize, sizes:[..] }`， 或以 total / page / page-size / sizes（逗號分隔）屬性設定。三段：資訊列（顯示第 X 到 Y 筆，共 T 筆資料）＋ 頁碼區（‹ 前一頁、頁碼、省略號、後一頁 ›，永遠含第 1／末頁／目前頁 ±1）＋「每頁顯示 N 筆」下拉。 getter：page / pageSize / pageCount。方法：setTotal(total, page?)（重繪但不派事件）。事件：page-change { page, pageSize }（改每頁筆數時 page 重置為 1）。

（page-change 結果顯示於此）

fb-export-dialog

自訂匯出報表對話框（可復用、與報表資料無關）。方法：open(config?) / close()。事件：export { time, metrics, detailLevel, summary } / cancel。 config：time（monthly|weekly）、metrics（['mtd','ytd','mom','yoy','monthlyize'] 子集）、detailLevel（affiliate|category|household|account）、summary（['subtotal','total'] 子集）、marketShareMode、partialMonthMode。 區塊：報表時間維度 / 統計比較指標（可多選）/ 客戶明細層級（四層級）/ 彙總計算（可多選：包含小計、包含總計）。 連動：客戶明細層級＝「客戶帳號明細」（account）時，彙總計算兩張卡片強制取消勾選＋停用（區塊標題不淡化）、export payload 的 summary 為 []；切回其他層級還原為兩項皆選。 狀態：預設（明細層級＝集團戶彙總、彙總計算兩項皆選）/ 佔比（月化停用＋tooltip）/ 非整月簡化模式（頂部警告＋僅「報表時間維度」「統計比較指標」兩區停用且皆不預設選取；客戶明細層級與彙總計算維持與 1 號情境相同）/ Loading（按匯出後約 0.8s 自動關閉）。 尺寸：60vw / 80vh（無最大高度上限）。開啟時鎖定底層頁面捲動（跨 modal 通則）。 （Default / 佔比指標 / 非1號開始 / 客戶帳號明細(無彙總計算) / 非1號開始+客戶帳號明細 / Loading）

（export / cancel 結果顯示於此）
